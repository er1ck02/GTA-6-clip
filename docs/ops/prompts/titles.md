# Titles and captions

## v1 (live, from research/title-bank.md, 2026-11-22)
- Lowercase, 3-8 words, typed like a text. One emoji at the end (😭 default, 😳 💀).
- Name the streamer as fans write it (tg, ludwig, speed, xqc, lacy).
- Say what happened or react to it; don't spoil the punchline; no clickbait, no Title Case.
- Never "rp" or "role play". "pulled a ricky spanish" is fine when it fits.
- Hashtags (2-4) in the description/caption: #gta6 #<streamer> + #shorts (YouTube) or #fyp (TikTok).
- Credit line on every post: "Credit: <Streamer>'s live stream, go follow them".
